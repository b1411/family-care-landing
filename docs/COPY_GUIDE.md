# UMAI Health — Гайд по тексту (Copy Guide)

Единый источник правды для всего текста на сайте. Цель — **минимализм, точность,
один голос**. Меньше слов, больше смысла. При любом тексте сверяйся с этим файлом.

---

## 1. Голос бренда

**Один регистр: уверенно-деловой, с человечностью в деталях.**

Мы — серьёзный медтех-продукт, а не рекламный лендинг и не справочник.
Говорим спокойно, по делу, доказываем фактами.

| ✅ Делаем | ❌ Не делаем |
|---|---|
| Спокойные утверждения, подкреплённые фактом | Рекламные восклицания («Начните сейчас!») |
| Конкретику и числа | Воду («инновационное решение», «меняет всё») |
| Уважение к читателю и его документам | Бытовое пренебрежение («бумажка») |
| Человечность в примерах и деталях | Сюсюканье и инфантильность |
| Сдержанные обещания | Абсолюты («невозможно», «полное соответствие») |
| Лирику — только на странице «О нас» | Лирику в hero и деловых блоках |

**Тон по аудиториям** (голос один, акцент разный):
- `/for-families` — тёплый, про спокойствие и контроль. Человек, не пациент.
- `/for-clinics` — деловой, про деньги, время и удержание. Доказательства.
- `/security`, `/integrations` — точный, технический, честный (эталон уже есть).

## 2. Глоссарий — одно слово на сущность

**Правило: одна сущность = одно слово на всём сайте.** Сверяйся с таблицей.

### Аудитория
- ✅ **«родители»**, **«семья»**
- ❌ убрать как именование сегмента: «мама», «мама и папа», «вы ждёте малыша»
- (в живых примерах-историях «мама»/«папа» допустимы как персонажи, не как сегмент)

### Экраны и роли
| Сущность | ✅ Единое название | ❌ Убрать |
|---|---|---|
| Экран координатора | **панель координатора** | рабочий стол, дашборд координатора |
| Экран руководителя | **дашборд руководителя** | панель руководителя |
| Экран главврача | **кабинет главврача** | командный центр |
| Приложение семьи | **приложение** | — |
| Кол-во ролей | называть честно: **родитель, координатор, руководитель, главврач** (4). Если нужно «3» — это «родитель · координатор · руководитель», главврач — отдельная воронка | «3 роли» там, где фигурирует и главврач |

### Действие в интерфейсе
- ✅ **«одно нажатие»** / «в одно нажатие»
- ❌ тап, клик, касание, «в 2 клика»

### Медицинские термины
| ✅ Русский | ❌ Англицизм / жаргон |
|---|---|
| соблюдение назначений | adherence, адхеренс |
| неявка | no-show |
| полный список прививок без расшифровки аббревиатур только на /for-clinics; на /for-families — с пояснением | сырые ИПВ/PCV13/Hib без расшифровки |

### Прививки — одна система именования
- ✅ Дозы — формат **«#N»**: «АКДС #1», «АКДС #2», «Гепатит B #1» (доминирующая форма, к ней приведены все)
- ✅ Ревакцинация — словом: «АКДС, ревакцинация», «Пневмококк, ревакцинация» (не «бустер»)
- ❌ вперемешку «АКДС-2», «(1-я)», «бустер»
- Нацкалендарь — всегда: **«национальный календарь РК»** (не «нацкалендарь», не «календарь Казахстана»)

### Числа — одно значение везде
- События маршрута: **50+** (убрать «47»)
- Прививки: **18** (убрать «18+»)
- Срок маршрута: **«от первых недель беременности до 2 лет»** (одна формула; убрать разнобой «зачатие / первая неделя / планирование»)

### Англицизмы → русский (перевести везде в пользовательском тексте)
| Англицизм | ✅ Русский |
|---|---|
| White-label | под вашим брендом |
| Care Plan Engine | Маршрут здоровья |

## 3. Антидубли — каждый блок говорит своё

**Принцип: одна мысль — одно место.** Если два блока говорят одно — оставляем один.

- **Главная:** `WhatIs` + `ProductShowcase` + `ModulesShowcase` пересказывали одно
  трижды. Решение: **каждый блок отвечает на свой вопрос**:
  - `WhatIs` → *что это* (1 абзац, без перечня фич)
  - `ProductShowcase` → *как выглядит* (три интерфейса, без повтора фич словами)
  - `ModulesShowcase` → *что внутри* (модули списком, без пересказа)
- **/for-clinics:** `ClinicProblemsSection` показывал одну мысль 4 способами
  (карточки + воронка + таблица + таймлайн). Решение: **оставить 1–2 сильных**,
  остальное убрать.
- Факт «50+ событий» / срок маршрута — упоминаем **один раз заметно**, не в каждом блоке.

## 4. Запрещённые заявления (доверие B2B)

- ❌ «Обойти это невозможно» → ✅ «изолирует данные на уровне СУБД»
- ❌ «Полное соответствие закону» → ✅ «построено в соответствии с Законом РК…»
- ❌ выдуманные точные проценты под видом данных без пометки «оценка»
- Согласовать факт хранения данных: по умолчанию ЕС, опционально РК — **одинаково**
  на `/security` и в FAQ `/for-clinics` (сейчас противоречат).

## 5. Микро-правила

- Кириллица «А» не латинская «A» (был разнобой в «Гепатит A»).
- Запятые при «кроме», «который»: «Никто, кроме вас и врача».
- «месяцев» при числе 24 (не «месяца»).
- Без эмодзи в деловом тексте (в мокапах-примерах — точечно, осознанно).
